# B1 – Ideal Siphon Modelling

B1 documents the lossless siphon solution set. The derivations in
`docs/ideal_without_losses.md` are now paired with executable code in
`simulations/ideal.py`, which exposes:

* Closed-form evaluators for instantaneous velocity, drainage time, and pressure
  distributions.
* A `simulate_ideal` helper that samples the analytical solution on arbitrary
  time grids for plotting or regression tests.
* Crest-pressure diagnostics that default to `TubeGeometry.crest_height` and can
  be tuned per geometry via `TubeGeometry.entry_height`.

Part B1 therefore links theory to working software and supports both quick
analytical checks and automated validation through the new unit tests in
`tests/test_simulations.py`.
