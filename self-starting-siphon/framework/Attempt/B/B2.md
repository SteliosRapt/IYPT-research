# B2 – Siphons with Losses

B2 extends the Part B models to incorporate distributed and minor losses. The
analytical roadmap in `docs/constant_losses.md` is implemented by
`simulations/constant_losses.py`, offering:

* Closed-form updates for velocity decay, reservoir height, and drainage time in
  the presence of a constant head-loss coefficient \(\Lambda\).
* Drop-in compatibility with the ideal solver so that plots, notebooks, and
  regression tests can compare lossless and lossy predictions directly.

For Reynolds-number-dependent and geometry-aware losses, the new
`simulations/variable_losses.py` module numerically integrates the nonlinear
drainage ODE while:

* Computing Darcy friction factors with laminar/turbulent regime detection via a
  Swamee–Jain approximation.
* Tracking crest pressure to flag cavitation and reporting the evolving total
  loss coefficient and outlet Reynolds number.

These tools deliver the “promised code” referenced in the documentation and set
the stage for advanced geometries and validation work.
