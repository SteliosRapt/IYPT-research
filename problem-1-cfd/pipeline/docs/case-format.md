# Case Format

## `case.schema.json`

- `schemaVersion`
- `caseId`
- `displayName`
- `parameters`
- `derived`
- `geometry`
- `meshing`
- `solver`
- `forcing`
- `eventThresholds`
- `outputs`
- `runStatus`
- `provenance`

## `run-manifest.schema.json`

- `schemaVersion`
- `caseId`
- `displayName`
- `timeSteps`
- `chartSeries`
- `geometryAssets`
- `fluidAssets`
- `events`
- `status`
- `paraview`
- `metadata`
